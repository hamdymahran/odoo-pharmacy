# نقطة بيع الصيدليات — Pharmacy POS (أودو 15)

موديول متكامل يحوّل نقطة بيع أودو إلى نظام صيدلية احترافي متوافق مع متطلبات السوق السعودي.

تطوير: **Hamdy Mahran** · الترخيص: LGPL-3

---

## المزايا

| الميزة | الوصف |
|---|---|
| الصلاحية والدفعات | تتبّع Lot + تاريخ صلاحية، منع بيع المنتهي، تنبيه قُرب الانتهاء، اختيار تلقائي FEFO |
| الوصفات الطبية | فرض تسجيل الوصفة على أدوية Rx قبل الدفع، مع بيانات المريض والطبيب |
| المواد المخدّرة | سجل تلقائي لكل صرف مادة مراقَبة مربوط بالوصفة والمريض والصيدلي |
| رصد / DTTS | تكامل SOAP مع نظام تتبّع الأدوية (GTIN+SN)، عملية Pharmacy Sale عند البيع |
| ZATCA | حقول الفاتورة الضريبية (QR/UUID) جاهزة للربط |
| بيانات الدواء | المادة الفعّالة، التركيز، الشكل الصيدلاني، الشركة، البدائل |
| التنبيهات | مهمة يومية (cron) لتحديث الصلاحية وتنبيه انتهاء تسجيل SFDA |

## التثبيت

1. انسخ المجلد `mdev_pharmacy_pos` إلى مجلد addons الخاص بأودو.
2. (اختياري، لرصد/DTTS فقط) ثبّت مكتبة zeep. المديول يعمل بدونها، ويتعطل الربط مع رصد فقط:
   ```
   pip install zeep
   ```
3. فعّل وضع المطوّر → التطبيقات → حدّث القائمة → ثبّت **Pharmacy POS**.
4. امنح المستخدمين مجموعة **صيدلي** أو **مدير صيدلية**.

## الإعداد

- **المنتجات**: فعّل "منتج دوائي" في بطاقة المنتج، واملأ تبويب "بيانات الصيدلية".
- **الدفعات**: أدخل تاريخ الصلاحية في كل دفعة (stock.production.lot).
- **نقطة البيع**: من إعدادات POS فعّل مزايا الصيدلية (منع المنتهي، فرض الوصفة...).
- **رصد**: من قائمة الصيدلية → رصد/DTTS → الإعدادات، أدخل GLN وبيانات SFDA.

## ملاحظات تنظيمية

- تكامل رصد و ZATCA يتطلب اعتمادات حقيقية من SFDA وهيئة الزكاة. الموديول يوفّر النموذج والـ hooks، ويُربط بالاعتمادات عند توفّرها.
- اختبر تكامل رصد على بيئة الاختبار قبل الإنتاج.
